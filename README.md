# Kymosketch

Allows for tracking of kymographs using hand drawn initialisation traces in a popup gui rather than automated trace detection. The initialisation traces are then refined using built in pylake functions. This allows for much finer control over which traces you do and don't want to analyse as well as where they start and end, whilst still giving reproducible tracks. 

Packages you will need to install:

  -pylake 1.2.0
  -cv2 4.8.0
  -peakutils 1.3.4
